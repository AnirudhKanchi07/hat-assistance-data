# Human-autonomy teaming behavior dataset

Behavior logs from 47 participants who each played up to 6 scenarios with a team of 6 robots. Each session is 20 decision steps. The dataset contains task states, each agent's beliefs and Q-values, and the actions of every agent.

- `data/`: the dataset. See `data/README.md` for every column.
- `code/load_data.py`: loads one scenario into pandas.
